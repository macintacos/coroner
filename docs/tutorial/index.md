# Tutorial

*Audience: people new to coroner who want to learn it by using it.*

The tutorial takes you through building one investigation timeline from start to finish,
with every command and the output to expect, so you finish having used coroner rather than
having read about it. To get a particular job done, use the
[how-to guides](../how-to/index.md) instead.

- [Your first timeline](first-timeline.md): create a timeline for an incident, add events
  and annotations, view it and export it as Markdown.
